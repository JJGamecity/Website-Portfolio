Banking API

02

A backend API in development for user and bank-account CRUD operations, built with Java and Spring Boot. Implements RESTful endpoints, DTOs, service and repository layers, JPA/Hibernate entity relationships, validation, and secure data handling. Uses MapStruct for DTO mapping and follows a layered architecture to keep business logic organized and maintainable. Includes custom exception handling and structured request/response models to provide consistent API responses and improve scalability.

03

Created 10 custom combat abilities inspired by One Punch Man, using Bézier-curve effects, reusable hit detection, damage and cooldown modules, and client-server VFX. Designed the abilities to deliver responsive combat interactions while keeping the underlying systems modular and reusable. Implemented unique attack patterns, animations, visual effects, and combat logic to bring each ability to life and create distinct gameplay experiences.
